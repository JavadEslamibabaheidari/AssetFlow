# Plans

This directory contains living plans for substantial work and milestones.

Milestone implementation can start only after the milestone plan passes the start gate in `docs/ai-development-workflow.md`:

- the milestone goal, scope, non-goals, deliverables, acceptance criteria, task breakdown, dependencies, risks, testing strategy, and GitHub tracking are written down
- implementation-blocking decisions are decided or explicitly deferred out of scope
- no unresolved `TBD`, `TODO`, `unknown`, `undecided`, or blocking open questions remain
- GitHub tracking matches the local plan
- durable planned behavior is reflected in `docs/knowledge/`

If the gate fails, keep planning. If it passes, mark the milestone plan `Status: Ready to start` and begin the first prioritized task.
